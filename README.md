# قاموس مصطلحات AWS CWI (اللحام) - تطبيق أندرويد

تطبيق أندرويد كامل لمذاكرة مصطلحات شهادة **AWS Certified Welding Inspector** بالعربي والإنجليزي.

## المميزات
- **قاموس كامل**: 160 مصطلح لحام مقسمة على 12 قسم (عيوب اللحام، عمليات اللحام، رموز اللحام، طرق الفحص غير الإتلافي، السلامة، الميتالورجي، وغيرها).
- **نطق صوتي (TTS)** لكل مصطلح بالإنجليزي والعربي.
- **جدول مذاكرة ذكي** بنظام التكرار المتباعد (Spaced Repetition): المصطلحات اللي بتتذكرها بتتباعد فترات مراجعتها، واللي بتنساها بترجع فوراً.
- **إشعارات يومية** بمصطلح عشوائي في الوقت اللي تحدده.
- **ويدجت للشاشة الرئيسية** يعرض "مصطلح اليوم".
- بحث وفلترة حسب القسم، وتحديد مصطلحات كمفضلة.

## طريقة البناء (Build)
1. حمّل [Android Studio](https://developer.android.com/studio) (أحدث نسخة، Ladybug أو أحدث).
2. فك ضغط الملف ده وافتح المجلد من Android Studio: **File → Open** → اختر مجلد `CWIGlossaryApp`.
3. Android Studio هيسألك تنشئ Gradle Wrapper تلقائياً — اختر **OK/Yes**، وسيبه يعمل Sync (محتاج إنترنت أول مرة عشان ينزل المكتبات).
4. وصّل موبايل أندرويد (فعّل خيارات المطورين + USB Debugging) أو استخدم Emulator.
5. اضغط ▶️ **Run** لتثبيت التطبيق.
6. لعمل ملف APK جاهز للتوزيع: **Build → Build Bundle(s) / APK(s) → Build APK(s)**.

## إضافة الويدجت للشاشة الرئيسية
بعد تثبيت التطبيق: اضغط مطولاً على الشاشة الرئيسية للموبايل ← "ويدجت" (Widgets) ← دوّر على "CWI Glossary" ← اسحبه للشاشة الرئيسية.

## هيكل المشروع
```
app/src/main/java/com/cwiglossary/app/
├── MainActivity.kt          # نقطة الدخول + Navigation
├── data/                    # قاعدة البيانات (Room) + النطق (TTS) + الإعدادات (DataStore)
├── ui/                      # شاشات Compose (الرئيسية، القاموس، المذاكرة، الإعدادات)
├── notification/            # جدولة وتنفيذ الإشعارات اليومية (WorkManager)
└── widget/                  # ويدجت الشاشة الرئيسية (Glance)
app/src/main/assets/terms.json  # بيانات القاموس (160 مصطلح)
```

## تعديل أو إضافة مصطلحات
عدّل ملف `app/src/main/assets/terms.json` مباشرة (كل مصطلح فيه: id, category, en, en_def, ar, ar_def)، ثم امسح التطبيق وأعد تثبيته عشان يعيد تحميل القاعدة من الملف.
